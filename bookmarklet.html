🔖 Récupérer Leboncoin depuis votre navigateur

Gratuit, illimité, sans rien installer. Les annonces sont lues depuis votre session Leboncoin (votre connexion, vos cookies) — donc aucun blocage, contrairement au serveur.

Le favori « ImmoRadar »

C'est un simple marque-page. On ne l'installe pas : on le glisse dans la barre des favoris.

📡 Envoyer vers ImmoRadar

Sur ordinateur (Chrome, Edge, Firefox)

1
Affichez votre barre de favoris si besoin : Ctrl + Maj + B.
2
Glissez le bouton bleu « 📡 Envoyer vers ImmoRadar » ci-dessus dans votre barre de favoris. (Une seule fois.)
3
Ouvrez Leboncoin sur la zone voulue : 🔍 Ouvrir Leboncoin — zone Villeneuve-Loubet
Vous pouvez affiner les critères directement sur Leboncoin : le favori récupère ce qui est affiché.
4
Sur la page de résultats Leboncoin, cliquez le favori « 📡 Envoyer vers ImmoRadar ». Il vous demande combien d'annonces importer (il affiche le total disponible) puis ouvre chaque annonce pour en lire la description — c'est là que se trouvent les charges, le loyer réel et le bail commercial (résidence gérée type Studéa, Belambra…). Comptez ~1 seconde par annonce : 40 annonces ≈ 40 s. Un message confirme le nombre envoyé.
5
Revenez sur ImmoRadar : vos annonces sont là, analysées selon les 2 stratégies.
Comptez ~1 seconde par annonce lue. Si Leboncoin restreint temporairement l'accès, patientez quelques minutes et relancez avec un nombre plus petit.

Sur iPhone (Safari)

Un peu plus manuel, à faire une seule fois :

1
Ajoutez cette page en favori (bouton Partager → Ajouter un signet).
2
Copiez le code du favori ci-dessous : 📋 Copier le code
3
Ouvrez vos Signets, modifiez celui que vous venez de créer, effacez son adresse et collez le code copié à la place. Renommez-le « ImmoRadar ». Enregistrez.
4
Allez sur une page de résultats Leboncoin, ouvrez vos Signets et touchez « ImmoRadar ». Les annonces partent vers l'app.
⚠️ Le favori ne fonctionne que sur une page de résultats de recherche Leboncoin (la liste d'annonces), pas sur la page d'accueil ni sur une annonce seule.
